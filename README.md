# HeyMode Wholesale (مبدا) و HeyMode Client Importer (مشتری)

- مبدا: `heymode-wholesale.php` + `includes/` — Snapshot محصولات و REST API (`API_CONTRACT.md`).
- مشتری: `heymode-client-importer/` — Import و سینک قیمت/موجودی.

## اتصال مبتنی بر دامنه (مبدا ۱.۱۱.۰ / مشتری ۰.۸.۰)

مدیر مبدا در «HeyMode Wholesale ← سایت‌های مشتری» دامنه را ثبت می‌کند (وضعیت: در انتظار فعال‌سازی). افزونه‌ی سایت مشتری خودکار فعال می‌شود: دامنه و یک راز تصادفی نصب را می‌فرستد، مبدا با یک درخواست برگشتی (HMAC) مالکیت دامنه را می‌سنجد و کلید اختصاصی را یک‌بار می‌دهد. کلید فقط به‌صورت hash در مبدا ذخیره می‌شود و مشتری هیچ آدرس/کلیدی نمی‌بیند یا وارد نمی‌کند.

- **غیرفعال‌کردن** یک سایت همان لحظه اثر می‌کند (`hmw_site_disabled`): سینک/Import/فهرست آن سایت بدون هیچ تغییری در قیمت/موجودی/محصولات متوقف می‌شود.
- **صدور دوباره**: کلید قبلی باطل و سایت دوباره «آماده فعال‌سازی» می‌شود؛ مشتری خودکار کلید تازه می‌گیرد.
- **کلید مشترک قدیمی**: بعد از آپدیت پیش‌فرض روشن است تا هیچ سایتی (از جمله test.heymode.ir) قفل نشود؛ بعد از فعال‌شدن همه‌ی سایت‌ها با تأیید صریح خاموش شود. راه برگشت: دکمه‌ی «روشن کردن دوباره» یا `define('HMW_FORCE_LEGACY_KEY', true);`.
- ثابت‌های wp-config مبدا: `HMW_ALLOW_INSECURE_HTTP` (فقط محیط محلی)، `HMW_TRUSTED_IP_HEADER` (پشت CDN)، `HMW_FORCE_LEGACY_KEY`.
