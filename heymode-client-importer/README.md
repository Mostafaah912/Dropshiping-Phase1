# HeyMode Client Importer

پلاگین سایت مشتری برای اتصال به API `heymode-wholesale`، Import واقعی محصولات به ووکامرس، و سینک روزانه قیمت/موجودی.

## نیازمندی‌ها

- WooCommerce فعال (Action Scheduler همراه آن نصب می‌شود — این پلاگین برای Import پس‌زمینه و زمان‌بندی سینک روزانه به آن متکی است).
- PHP ≥ 8.1

## راه‌اندازی

1. **اتصال**: در «HeyMode Import ← اتصال» آدرس API و کلید سایت مبدا (`heymode-wholesale`) را وارد و «تست اتصال» کنید.
2. **قیمت‌گذاری**: در «HeyMode Import ← قیمت‌گذاری» فرمول (مبلغ ثابت + درصد) و وضعیت پیش‌فرض بعد از Import را تنظیم کنید.
3. **محصولات**: از «HeyMode Import ← محصولات» محصولات را انتخاب، ویرایش (نام/توضیح کوتاه/تصاویر) و به مرحله بازبینی ببرید؛ از آنجا «وارد کن» یا «Import همه» را بزنید. Import هر محصول به‌صورت یک Action مجزا در پس‌زمینه (Action Scheduler) اجرا می‌شود؛ صفحه بازبینی وضعیت هر ردیف را با Polling سبک (فقط از جدول ردیابی، بدون تماس با منبع) نشان می‌دهد.

## سینک روزانه قیمت/موجودی

هر روز ساعت **۰۶:۰۰ به وقت تهران** پلاگین به‌صورت خودکار فقط **قیمت و موجودی** محصولاتی که قبلاً Import شده‌اند را از منبع به‌روز می‌کند (نام/توضیح/تصویر/دسته‌بندی هرگز overwrite نمی‌شوند؛ محصولاتی که در منبع غیرفعال شده‌اند فقط Out of Stock می‌شوند، نه حذف/Draft).

### Action Scheduler (پیش‌فرض، بدون تنظیم اضافه)

این زمان‌بندی از طریق Action Scheduler (همراه ووکامرس) انجام می‌شود که خودش با هر بازدید صفحه‌ای از سایت (Pseudo-Cron وردپرس) اجرا می‌شود. برای **اکثر سایت‌ها** همین کافی است.

### Cron واقعی سرور + WP-CLI (برای سایت‌های کم‌بازدید)

اگر سایت شما بازدید کمی دارد (و Pseudo-Cron وردپرس ممکن است دیر یا اصلاً اجرا نشود)، به‌جای تکیه صرف بر Action Scheduler، یک Cron واقعی سرور برای اجرای مستقیم دستور WP-CLI زیر تنظیم کنید:

```bash
# در crontab سرور (مثلاً crontab -e):
0 6 * * * cd /path/to/wordpress && wp hci sync --quiet
```

این دستور دقیقاً همان منطق دکمه‌ی **«Sync Now»** در «HeyMode Import ← سینک روزانه» را اجرا می‌کند (کورسر را فقط بعد از موفقیت کامل جلو می‌برد، و اگر منبع خطا/۴۲۹ بدهد، هیچ قیمت/موجودی‌ای در مقصد تغییر نمی‌کند).

می‌توانید هر دو راه (Action Scheduler + Cron واقعی) را همزمان روشن نگه دارید — چون سینک فقط وقتی Cursor واقعاً جلو می‌رود که یک اجرا کامل و موفق باشد، اجرای همزمان/تکراری بی‌ضرر است (اجرای دومِ نزدیک به هم عملاً چیزی برای به‌روزرسانی پیدا نمی‌کند).

## دستور WP-CLI

```bash
wp hci sync
```

سینک را بلافاصله و به‌صورت همزمان (Synchronous) اجرا و خلاصه‌ی نتیجه (بررسی‌شده/قیمت به‌روزشده/موجودی به‌روزشده/خطاها) را چاپ می‌کند.

## اطلاعات فنی (برای پشتیبان فنی)

- صفحه «بروزرسانی قیمت و موجودی» فقط اطلاعات ساده نشان می‌دهد؛ جزئیات فنی (زمان دقیق UTC آخرین نقطه هماهنگی و دستور Cron سرور) پشت لینک کم‌رنگ «تنظیمات پیشرفته» در پایین همان صفحه است.
- ردیف‌های واردشده خودکار از جدول بازبینی حذف می‌شوند؛ «حذف از این لیست» فقط انتخاب ذخیره‌شده کاربر را برمی‌دارد و ردیف در صف را حذف نمی‌کند.
